# Support

Use the GitHub issue forms for reproducible bugs, feature proposals, and
questions about the guides in `docs/`. Search existing issues first and note
the commit SHA you are running.

This project is under active development. It does not
promise response or resolution times, and there is no hosted version to
support: you run it yourself with `npm run dev` or `npm run build && npm start`.

Do not use a public issue for a possible security problem. Follow
[SECURITY.md](SECURITY.md). Never submit API keys, bot tokens, push
subscriptions, exported task files, or unredacted screenshots.

For a bug, include:

- the commit SHA;
- Node and npm versions, browser and version, and operating system;
- whether it happens in demo mode (`/?demo=1`);
- the guide and exact step followed; and
- what you expected and what happened.

For questions about a third-party model provider, Telegram, or the content of
a public calendar feed, contact that provider.
